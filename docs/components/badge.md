# Badge 徽标

> Badge

出现在按钮或头像旁的徽标数字。

## 示例

<nv-space>
  <nv-badge value="5"><nv-button>消息</nv-button></nv-badge>
  <nv-badge value="100" max="99"><nv-button>最大值</nv-button></nv-badge>
  <nv-badge dot><nv-button>圆点</nv-button></nv-badge>
</nv-space>

## 用法

```vue
<nv-badge value="12" max="99"><nv-button>消息</nv-button></nv-badge>
```
