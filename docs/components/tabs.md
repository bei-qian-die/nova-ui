# Tabs 标签页

> Tabs

选项卡切换，支持方向键导航。

## 示例

<nv-tabs><nv-tab-pane label="标签一" name="a">内容一</nv-tab-pane><nv-tab-pane label="标签二" name="b">内容二</nv-tab-pane></nv-tabs>

## 用法

```vue
<nv-tabs v-model="active">
  <nv-tab-pane label="标签一" name="a">内容一</nv-tab-pane>
  <nv-tab-pane label="标签二" name="b">内容二</nv-tab-pane>
</nv-tabs>
```
