# 无障碍

Nova UI 内置完整的无障碍与键盘导航能力：

| 能力 | 组件 |
| --- | --- |
| 焦点陷阱 / Esc 关闭 / 焦点归还 | Modal、Drawer |
| ARIA 属性 | 全部组件（role、aria-*） |
| 键盘导航（方向键 / Tab） | Select、Tabs、Slider、Rate |
| 焦点可见（focus-visible） | Button、Input、Link 等 |
| `role="switch"` / `aria-checked` | Switch |
| `role="dialog"` / `aria-modal` | Modal、Drawer |

所有交互组件均通过 `vitest-axe` 自动化无障碍扫描。
