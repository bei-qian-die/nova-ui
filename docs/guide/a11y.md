# 无障碍

Nova UI 内置完整的无障碍与键盘导航能力：

| 能力 | 组件 |
| --- | --- |
| 焦点陷阱 / Esc 关闭 / 焦点归还 | Modal、Drawer |
| ARIA 属性 | 全部组件（role、aria-*） |
| 键盘导航（方向键 / Tab） | Select、Tabs、Slider、Rate |
| 焦点可见（focus-visible） | Button、Input、Link 等 |
| `role="switch"` / `aria-checked` | Switch |
| `role="dialog"` / `aria-modal` | Modal、Drawer |

## 键盘操作契约表

| 组件 | 键位 | 行为 |
| --- | --- | --- |
| Tabs | `←` / `↑`、`→` / `↓`、`Home`、`End` | roving tabindex，selection follows focus（选中项随焦点移动） |
| Select | `↑` / `↓`、`Enter`、`Esc`、`Home` / `End` | 移动高亮 / 选中 / 关闭并归还焦点 / 跳到首末项 |
| Modal / Drawer | `Tab`、`Shift+Tab`、`Esc` | 焦点在面板内循环（焦点陷阱）/ 关闭并归还焦点到触发元素 |
| Switch | `Space` | 切换 `aria-checked` |
| Slider | `←` / `↓`、`→` / `↑`、`Home`、`End` | 步进减 / 步进增 / 跳到最小值 / 跳到最大值 |

所有交互组件均通过 `vitest-axe` 自动化无障碍扫描。
